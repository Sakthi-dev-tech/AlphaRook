SVG originals are unchanged except for descriptive filenames.
PNG versions are 256 x 256 rasterizations with transparent backgrounds.
PNG rasterization: rsvg-convert --width 256 --height 256 --output piece.png piece.svg
Filenames: {white|black}_{king|queen|rook|bishop|knight|pawn}.{png|svg}
PNGs are in this folder; SVG originals are in svg/.

Raylib example (run from project root):
Texture2D king = LoadTexture("assets/chess/white_king.png");
UnloadTexture(king); // before closing the window
